# Test Data Directory

This directory contains sample bot payload files for testing.

## Files to Create:
- `valid_sr_payload.json` - Valid service request payload
- `missing_fields_payload.json` - Payload with missing required fields
- `invalid_format_payload.json` - Payload with invalid data formats
- `edge_case_payload.json` - Edge case scenarios

These files simulate what the bot might send to the service.
